1. PROJECT SUMMARY
- Single-file web app (index.html, ~3230 lines, 181 KB, vanilla JS, no build, no deps except Google GSI script).
- Hosted on GitHub Pages. User works from Android phone mostly. UI text is English.
- Purpose: bulk-replace wrongly translated terms across 100+ Google Docs chapters per novel in Drive ("My Work" folder), via Drive API (drive.readonly) + Docs API (documents).
- Docs contain ONLY translated text (English or similar). Languages in scope: JP/KR/CN/RU raw + English translation. NO Bengali-specific work anywhere in this plan (existing Bengali-safe code from v4.x stays untouched, nothing new added). Raw (JP/KR/CN/RU) can only be used if the user keeps raw chapters as Docs (S13+).
- All user data is in localStorage via helper `store` (get/set). Never remove or rename existing keys.
- Rule of the project: SINGLE FILE index.html. No extra runtime files (so no PWA, no CDN libs, no network calls other than Google).
- NO AI. Everything is rule/dictionary based. (Optional AI suggestions and Google Sheets master are PARKED, see section 8.)
