2Term pairs

Pair tools

Check pairs warns about very short terms, duplicates, chains (a result that a later pair changes again) and invalid patterns. Swap sides turns every "wrong => correct" into "correct => wrong", which is the easiest way to undo a replacement. Fix separators turns tab, -> and → into => (handy after pasting from a spreadsheet). Prepare undo of last run writes the reverse pairs of your last replace and limits the next run to the files it changed; then run Preview and untick anything that should stay.

Format: wrong => correct. Leave the correct part empty to delete that word. Several wrong spellings of one term can share a line, separated by " | " (example: tar bhai | tar bhaiya => his brother).

3Chapter range and options

The range uses the chapter number in the file name (Chapter 12, Ch 12, or the first number). Files without a number are skipped. Leave both empty for all chapters.

History of runs

Every finished replace is saved on this device with the chapters and the matches that were changed. Open a run to see it again, save its report, prepare an undo, or delete it. History is not part of the backup file.
